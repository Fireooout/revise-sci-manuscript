# Contributing

Thank you for helping improve revise-sci-manuscript.

## Before submitting a change

- Keep the skill focused on reproducible SCI manuscript revision.
- Do not include private manuscripts, raw data, credentials, or copyrighted full-text examples.
- Preserve the review-gated workflow and the protection of source data.
- Keep instructions concise and explain any new safety or validation rule.

## Suggested workflow

1. Create a focused branch.
2. Update the skill or its references.
3. Run the skill validator on skills/revise-sci-manuscript.
4. Test scripts with a temporary project directory.
5. Update the changelog when behavior changes.
6. Open a pull request with a clear summary and validation notes.

## Content principles

The skill must not fabricate scientific claims, citations, statistics, or source data. Changes that can alter scientific meaning should remain subject to author confirmation.
